## 📦 Что включено в Deployment Kit

### 1. Главный скрипт установки ⭐
**Файл:** `scripts/install.sh`

**Что делает:**
- ✅ Проверяет систему (Ubuntu/Debian)
- ✅ Устанавливает Node.js 18+
- ✅ Устанавливает все зависимости
- ✅ Создаёт пользователя `autoblog`
- ✅ Настраивает директории
- ✅ Настраивает PM2 для автозапуска
- ✅ Настраивает cron задачи
- ✅ Настраивает logrotate
- ✅ Проверяет установку

**Запуск:**
```bash
sudo bash scripts/install.sh
```

**Логи:** `/var/log/auto-blog/install.log`

---

### 2. Скрипт проверки здоровья

- ✅ Node.js процессы
- ✅ API ключи
- ✅ Логи на ошибки
- ✅ Cron задачи

**Запуск:**
```bash
sudo bash scripts/health-check.sh
```

---

### 3. Скрипт бэкапа
**Файл:** `scripts/backup.sh`

**Что делает:**
- ✅ Архивирует статьи

## 📋 Чек-лист для агента

Агент должен проверить и сделать:

### Перед установкой:
- [ ] ОС: Ubuntu 22.04 или Debian 12
- [ ] Доступ: root права
- [ ] Место: минимум 10GB свободно
- [ ] RAM: минимум 2GB

### Во время установки:
- [ ] Выполнить `install.sh`
- [ ] Проверить что нет ошибок в логах
- [ ] Убедиться что пользователь `autoblog` создан
- [ ] Проверить что `.env` создан

### После установки:
- [ ] Запустить `health-check.sh`
- [ ] Убедиться что все проверки пройдены
- [ ] Проверить что PM2 запущен
- [ ] Проверить что cron настроен
- [ ] Сообщить пользователю о необходимости добавить ANTHROPIC_API_KEY

---

## 🔐 Безопасность (встроена)

### Что уже настроено:
1. **Пользователь без root прав:**
   - Создаётся `autoblog` без sudo
   - Все файлы принадлежат autoblog

2. **API ключи защищены:**
   - `.env` имеет права 600 (только владелец)
   - Не попадает в git
   - Не виден другим пользователям

3. **Изоляция:**
   - Приложение в `/opt/auto-blog/`
   - Данные отдельно от кода
   - Логи в `/var/log/auto-blog/`

4. **Автоматическая очистка:**
   - Старые логи удаляются (logrotate)
   - Старые бэкапы удаляются (30 дней)
   - Ограничение ресурсов (Docker)

## ⚡ Быстрые команды (после установки)

### Для тебя (после установки агентом):

```bash
# 1. Переключиться на пользователя системы
sudo su - autoblog

# 2. Перейти в директорию
cd /opt/auto-blog/app

# 3. Добавить API ключи (nano или vim)
nano .env
# Добавить: ANTHROPIC_API_KEY=sk-ant-...

# 4. Сгенерировать первую статью
npm run generate-post "Твоя тема"

# 5. Проверить что создалось
ls -la output/
cat output/*/index.md
```

### Для агента (мониторинг):

```bash
# Проверка здоровья
/opt/auto-blog/scripts/health-check.sh

# Просмотр логов
tail -f /var/log/auto-blog/app.log

# Статус процессов
pm2 status
pm2 monit

# Бэкап
/opt/auto-blog/scripts/backup.sh
```
