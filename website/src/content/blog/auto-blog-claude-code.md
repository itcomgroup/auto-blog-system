# Как я автоматизировал блог через Claude Code: полный разбор системы

5 февраля 2026

Сегодня хочу поделиться системой, которая полностью изменила мой подход к ведению блога. Это не просто инструмент — это content-завод, который превращает каждую сессию с Claude Code в полноценную статью.

## Проблема: знания растворяются

Каждая сессия с Claude Code — это решённая задача. Настроил деплой, разобрался с API, нашёл баг в конфиге. В моменте всё понятно. Через неделю — чистый лист.

Я искал способ получить документацию своих решений без дополнительных усилий в процессе работы.

## Решение: сессия → статья

Идея простая: если каждая сессия и так содержит полезный контент, пусть AI превращает её в статью.

## Архитектура системы

```
Сессия с Claude Code
        │
        ▼
┌─────────────────────────────┐
│ blog-ideas-from-logs        │
│ (Извлечение тем из логов)   │
└─────────────────────────────┘
        │
        ▼
┌─────────────────────────────┐
│ blog-post                   │
│ • Exa research              │
│ • Генерация черновика       │
│ • deaify (4 критика)        │

        │

        │
        ▼

```

## Компоненты системы

### 1. Извлечение тем из логов (blog-ideas-from-logs)

Скрипт сканирует логи Claude Code в `~/.claude/logs/` и извлекает потенциальные темы для статей.

**Критерии хорошей темы:**
- Решена нестандартная задача
- Были ошибки и их решение
- Использованы конкретные технологии
- Может быть полезно другим

**Пример результата:**
```json
{
  "topic": "Настройка MIDI-контроллера Akai MPK mini для OBS",
  "complexity": 4,
  "technologies": ["obs", "midi", "hardware"],
  "context": "Решение проблемы с LED индикацией"
}
```

### 2. Генерация статьи (blog-post)

На основе темы создаётся полноценная статья через цепочку агентов:

**Шаг 1: Research через Exa**
```javascript
const results = await exa.searchAndContents(query, {
  numResults: 5,
  text: true
});
```

Exa возвращает Markdown вместо HTML — это удобнее для обработки LLM.

**Шаг 2: Генерация черновика**

Claude создаёт структуру:
- Заголовок (H1)
- Введение (проблема)
- Основная часть (решение)
- Практический пример (код)
- Выводы

**Шаг 3: Deaify — удаление "аишности"**

Запускается 4 параллельных критика:

**Критик 1: Шаблонные фразы**
```
❌ "Важно отметить, что..."
❌ "Стоит отметить, что..."
❌ "Необходимо понимать, что..."
→ Удалить или конкретизировать
```

**Критик 2: Ритм**
```
❌ Одинаковая длина предложений
❌ Однообразное начало абзацев
→ Варьировать длину, менять структуру
```

**Критик 3: Конкретика**
```
❌ "Это улучшает производительность"
→ "Улучшает производительность на 40%"

❌ "Многие разработчики используют"
→ "Я использую в 5 проектах"
```

**Критик 4: Общность**
```
❌ "Каждый выбирает сам"
❌ "Зависит от ситуации"
→ Выразить личное мнение, дать рекомендацию
```

**Шаг 4: Сборка HTML**

Создаётся финальный HTML с SEO-метатегами:
- Open Graph (для соцсетей)
- Twitter Cards
- Мета-описание
- Ключевые слова

### 3. Telegram Publisher

Публикует превью статьи в канал:

```
📝 Настройка MIDI-контроллера для OBS

Решение проблемы с LED индикацией через 
SysEx команды. Полное руководство...

#obs #midi #hardware

🔗 Читать полностью: ссылка
```

## Технический стек

- **AI:** Claude Code + Claude Opus 4.5
- **Поиск:** Exa API (возвращает Markdown)
- **Фронтенд:** Astro (статический генератор)
- **Бот:** Telegram Bot API
- **Плагины:** Superpowers для планирования

## Superpowers — секретное оружие

Использую плагин Superpowers, который помогает в планировании. Работает в:
- Claude Code
- OpenCode
- Antigravity

Помогает структурировать задачи и контекст перед началом работы.

## Практические инсайты

### 1. Логи — новое золото

Логи Claude Code содержат огромное количество полезной информации. Каждая сессия — потенциальная статья.

### 2. Цепочки агентов

Не пытайся сделать всё одним промптом. Разбей на этапы:
1. Research
2. Черновик
3. Критика
4. Финал

### 4. Deaify критично важен

Без удаления "аишности" текст звучит как генерированный AI. 4 критика параллельно — оптимальное решение.

### 5. Используй Haiku для субагентов

Для простых задач (критика текста) использую Claude Haiku — дешевле и быстрее Opus.

## Как попробовать самому

### Вариант 1: Полная система

```bash
# 1. Установка
npm install

# 2. Настройка окружения
cp .env.example .env
# Добавь API ключи

# 3. Извлечь идеи
npm run extract-ideas

# 4. Создать статью
npm run generate-post "Твоя тема"

# 5. Опубликовать
npm run publish-telegram ./output/article/
```

### Вариант 2: Начать с малого

Создай файл `~/.claude/skills/blog-post.md`:

```markdown
# Blog Post Skill

Когда пользователь просит создать статью:

1. Спроси тему
2. Сделай research через Exa
3. Напиши черновик
4. Проверь на "аишность":
   - Убери шаблонные фразы
   - Добавь конкретики
   - Добавь личное мнение
5. Сохрани в формате Markdown
```
