# Архитектура системы: Как всё работает

## 🎯 Главный принцип

Система работает **НЕЗАВИСИМО** от Claude Code! Это отдельное Node.js приложение, которое:
1. Читает логи сессий (любых: Claude Code, OpenCode, и т.д.)
2. Использует Claude API (через SDK) для генерации текста
3. Создаёт файлы (HTML, Markdown)
4. Может работать из командной строки

## 🔑 Ключевое понимание

### Что такое Claude API?

```javascript
// Это НЕ Claude Code! Это API для доступа к модели Claude
import Anthropic from '@anthropic-ai/sdk';

const claude = new Anthropic({
  apiKey: 'sk-ant-...'  // Ключ из https://console.anthropic.com/
});

// Отправляем промпт и получаем ответ
const response = await claude.messages.create({
  model: 'claude-3-5-sonnet-20241022',
  messages: [{ role: 'user', content: 'Напиши статью...' }]
});
```

**Claude API** ≠ **Claude Code**
- Claude API = доступ к модели через HTTP
- Claude Code = CLI приложение от Anthropic

## 🔄 Пошаговый процесс

### Шаг 1: Пользователь работает с AI
```bash
# Вы работаете в Claude Code, OpenCode, Cursor, etc.
$ claude  # или opencode

# Решаете задачу...
# "Настройка Docker для Rails"
# Логи автоматически сохраняются в ~/.claude/logs/
```

### Шаг 2: Запускается Auto Blog System
```bash
# В отдельном терминале (НЕ в Claude Code!)
$ cd ~/sereja-blog-project

# Извлекаем идеи из логов
$ npm run extract-ideas

# Что происходит:
# 1. Node.js читает файлы из ~/.claude/logs/
# 2. Отправляет содержимое в Claude API
# 3. Claude API возвращает JSON с темами
# 4. Сохраняем в output/ideas.json
```

### Шаг 3: Генерация статьи
```bash
# Создаём статью
$ npm run generate-post "Настройка Docker для Rails"

# Что происходит:
# 1. Node.js отправляет запрос в Exa API (поиск)
# 2. Node.js отправляет запрос в Claude API (генерация)
# 3. Node.js запускает 4 параллельных запроса (критики)
# 4. Node.js создаёт HTML и Markdown файлы
# 5. Сохраняем в output/2026-02-05-docker-rails/
```

### Шаг 4: Добавление на сайт
```bash
# Копируем статью на сайт
$ cp output/2026-02-05-docker-rails/index.md \
     website/src/content/blog/

# Собираем сайт
$ cd website && npm run build

# Получаем статические файлы в website/dist/
```

### Шаг 5: Деплой
```bash
# Загружаем на хостинг
# GitHub Pages / Vercel / Netlify / свой сервер
```

## 🆚 Claude Code vs OpenCode vs Auto Blog

| Компонент | Тип | Роль |
|-----------|-----|------|
| **Claude Code** | CLI приложение | Среда разработки (IDE) |
| **OpenCode** | CLI приложение | Альтернативная среда разработки |
| **Auto Blog System** | Node.js приложение | Отдельный инструмент для создания контента |
| **Claude API** | HTTP API | Используется Auto Blog для генерации текста |

## 📁 Где что находится

```
~/.claude/logs/           ← Логи Claude Code (автоматически)
~/.opencode/logs/         ← Логи OpenCode (если есть)
~/sereja-blog-project/    ← Auto Blog System (мы тут работаем)
  ├── src/               ← Исходный код Node.js
  ├── output/            ← Сгенерированные статьи
  └── website/           ← Сайт на Astro
```

## ✅ Проверка понимания

**Вопрос 1:** Нужен ли запущенный Claude Code для работы Auto Blog?
**Ответ:** НЕТ! Auto Blog использует Claude API (HTTP), а не Claude Code.

**Вопрос 2:** Можно ли использовать OpenCode вместо Claude Code?
**Ответ:** ДА! Нужно только настроить путь к логам в .env

**Вопрос 3:** Где выполняется команда `npm run generate-post`?
**Ответ:** В обычном терминале Linux, НЕ внутри Claude Code.

**Вопрос 4:** Нужен ли сервер Astro для генерации статей?
**Ответ:** НЕТ! Astro только отображает готовые статьи.

## 🚀 Самый простой способ начать

```bash
# 1. Открыть обычный терминал (НЕ Claude Code!)
$ cd ~/sereja-blog-project

# 2. Создать статью вручную (без API ключей!)
$ cat > output/my-first-post.md << 'EOF'
---
title: "Моя первая статья"
date: 2026-02-05
---

# Заголовок

Текст статьи...
EOF

# 3. Скопировать на сайт
$ cp output/my-first-post.md website/src/content/blog/

# 4. Открыть HTML напрямую
$ firefox output/demo-article/index.html
# или
$ google-chrome output/demo-article/index.html
```

**Готово!** Статья создана без API, без сервера, без Claude Code.
