# 🚀 ИНСТРУКЦИЯ ДЛЯ СЕРВЕРНОГО АГЕНТА

## 📋 Что нужно сделать

Этот документ — инструкция для серверного агента управления VPS. 
Агент должен развернуть Auto Blog System на сервере пользователя.

## ✅ Чек-лист задач

### Этап 1: Подготовка
- [ ] Проверить права root
- [ ] Проверить систему (Ubuntu/Debian)
- [ ] Проверить свободное место (минимум 10GB)
- [ ] Создать пользователя `autoblog`

- [ ] Запустить скрипт `scripts/install.sh`

- [ ] Убедиться что создан файл `/opt/auto-blog/app/.env`
- [ ] Сообщить пользователю о необходимости добавить API ключи
- [ ] Проверить права на файлы

### Этап 4: Проверка
- [ ] Запустить `scripts/health-check.sh`
- [ ] Убедиться что все сервисы работают
- [ ] Проверить логи

### Этап 5: Запуск
- [ ] Запустить тестовую генерацию статьи
- [ ] Проверить что статья создалась
- [ ] Сообщить пользователю о готовности

## 🔧 Команды для управления

### Проверка статуса
```bash
# Здоровье системы
/opt/auto-blog/scripts/health-check.sh

# Логи приложения
tail -f /var/log/auto-blog/app.log

# Статус процессов
pm2 status
```

### Ручной запуск
```bash
# Переключиться на пользователя autoblog
sudo su - autoblog
cd /opt/auto-blog/app

# Сгенерировать статью
npm run generate-post "Тема статьи"

# Извлечь идеи из логов
npm run extract-ideas
```

### Обновление
```bash
# Обновить код
cd /opt/auto-blog/app
sudo -u autoblog git pull

# Переустановить зависимости
sudo -u autoblog npm ci

# Перезапустить
pm2 restart auto-blog
```

### Бэкап
```bash
# Создать бэкап вручную
/opt/auto-blog/scripts/backup.sh

# Список бэкапов
ls -la /opt/auto-blog/data/backups/
```

## ⚠️ Важные замечания

### Безопасность
- ✅ Пользователь `autoblog` не имеет root прав
- ✅ API ключи хранятся в `.env` с правами 600
- ✅ Логи доступны только root и autoblog
- ✅ Порт 3000 доступен только локально (не извне)

### API Ключи
**ВАЖНО:** После установки пользователь ДОЛЖЕН сам добавить:
- `ANTHROPIC_API_KEY` — ключ для Claude API
- `EXA_API_KEY` — уже добавлен (dc2820df-89a6-4500-a5c7-97809566cc81)

Агент НЕ ДОЛЖЕН просить или сохранять API ключи пользователя!

### Логи AI агентов
Система автоматически найдёт логи:
- `~/.claude/logs/` — для Claude Code
- `~/.opencode/logs/` — для OpenCode

Если пути другие — пользователь должен указать в `.env`

## 📊 Мониторинг

### Что мониторить:
1. **Диск:** Не менее 20% свободного места
2. **Память:** Не более 80% использования
3. **Логи:** Отсутствие ERROR сообщений
4. **Cron:** Задачи выполняются по расписанию

### Алерты:
- Диск > 90% → Очистить старые логи/бэкапы
- Ошибки в логах → Перезапустить: `pm2 restart auto-blog`
- Не работает генерация → Проверить API ключи в `.env`

## 🆘 Troubleshooting

### Проблема: Нет прав на запись
```bash
# Решение:
sudo chown -R autoblog:autoblog /opt/auto-blog
```

### Проблема: Node.js не найден
```bash
# Решение:
source ~/.bashrc
nvm use 18
```

### Проблема: PM2 не запускается
```bash
# Решение:
pm2 startup systemd
pm2 save
```

### Проблема: Ошибка в скрипте установки
```bash
# Логи установки:
tail -f /var/log/auto-blog/install.log

# Перезапуск с пропуском этапов:
bash scripts/install.sh 2>&1 | tee install-debug.log
```
