## Архитектура skills

### 1. blog-ideas-from-logs
**Назначение:** Извлечение тем из логов Claude Code

**Как работает:**
- Сканирует `~/.claude/logs/`
- Ищет паттерны: "Настроить", "Разобраться", "Исправить", "Создать"
- Оценивает сложность (1-5)
- Ранжирует по полезности

**Выход:** JSON со списком тем

### 2. blog-post
**Назначение:** Генерация статьи из темы

**Цепочка агентов:**
```
Тема → Research (Exa) → Черновик → Deaify (4 критика) → HTML
```

**Важные детали:**
- Использует Exa для поиска информации
- 4 параллельных критика для улучшения текста
- Генерирует HTML с SEO-метатегами
- Добавляет Open Graph теги

### 3. deaify-text
**Назначение:** Удаление "аишности" из текста

**4 критика (параллельно):**
1. **Шаблонные фразы** — убирает "Важно отметить", "Стоит отметить"
2. **Ритм** — варьирует длину предложений
3. **Конкретика** — добавляет числа, версии, примеры кода
4. **Общность** — добавляет личное мнение

**Особенность:** Использует субагентов на Haiku для дешевизны

### 4. telegram-publisher
**Назначение:** Публикация в Telegram канал

**Формат поста:**
```
📝 Заголовок статьи

Описание (200 символов)

#тег1 #тег2 #тег3

🔗 Читать полностью: ссылка
```

### 5. brainstorm (упомянут)
**Назначение:** Уточнение задачи перед началом работы
- Используется для планирования
- Помогает сформулировать чёткое ТЗ

### 6. html-lesson (упомянут)
**Назначение:** Превращение транскрипта сессии в HTML-урок
- Добавляет навигацию
- Структурирует материал

## Процесс создания контента

### Полный pipeline:
```
1. Сессия с Claude Code (решение задачи)
   ↓
2. blog-ideas-from-logs (извлечение темы)
   ↓
3. blog-post (генерация статьи)
   ├─ Research через Exa
   ├─ Генерация черновика
   ├─ Deaify (4 критика)
   └─ HTML сборка
   ↓
4. Публикация:
   ├─ На сайт (автоматически)
   └─ В Telegram (через бота)
```

### Ключевые принципы:

1. **Learning in Public** — публикация процесса обучения
2. **Без дополнительных усилий** — статья создаётся из сессии
3. **Контекст из логов** — чем больше деталей, тем лучше статья
4. **Research через Exa** — статья содержит внешний контекст
