# Deaify Text Skill

Удаляет "аишность" из текста через 4 параллельных критика.

## Входные данные

- `text`: Текст для обработки (обязательно)
- `critics`: Список критиков (по умолчанию: все)
- `iterations`: Количество итераций (по умолчанию: 2)

## Критики

### 1. Шаблонные фразы (templates)

**Проблема:** AI любит стандартные конструкции

**Паттерны:**
```
❌ "Важно отметить, что..."
❌ "Стоит отметить, что..."
❌ "Необходимо понимать, что..."
❌ "Следует учитывать, что..."
❌ "Не секрет, что..."
❌ "Как известно..."
❌ "В современном мире..."
❌ "В эпоху цифровизации..."
```

**Решение:** Удалить или конкретизировать

### 2. Ритм (rhythm)

**Проблема:** Однообразное построение фраз

**Паттерны:**
```
❌ Все предложения одинаковой длины
❌ Каждый абзац начинается одинаково
❌ Отсутствие коротких фраз
❌ Монотонная структура
```

**Решение:**
- Варьировать длину (короткие + длинные)
- Менять начало абзацев
- Добавить диалоги/вопросы

### 3. Конкретика (specificity)

**Проблема:** Общие фразы без деталей

**Паттерны:**
```
❌ "Это улучшает производительность"
❌ "Данный подход эффективен"
❌ "Многие разработчики используют"
❌ "Существует несколько способов"
```

**Решение:**
- Добавить числа: "на 40% быстрее"
- Конкретные версии: "Node.js 18+"
- Имена файлов: "в `.claude/skills/blog-post/config.json`"
- Даты: "в январе 2026"

### 4. Общность (generality)

**Проблема:** Очевидные истины без мнения

**Паттерны:**
```
❌ "Каждый выбирает сам"
❌ "Зависит от конкретной ситуации"
❌ "Есть плюсы и минусы"
❌ "Всё индивидуально"
```

**Решение:**
- Выразить личное мнение
- Дать рекомендацию
- Рассказать о своём опыте
- Сделать выбор за читателя

## Пример работы

**Исходный текст:**
```
Важно отметить, что настройка MIDI-контроллера для OBS 
требует внимания к деталям. Необходимо понимать, что 
каждый контроллер имеет свои особенности. Существует 
несколько способов подключения.
```

**После deaify:**
```
Настройка MIDI-контроллера для OBS отнимает у меня 
20-30 минут каждый раз. Akai MPK mini требует особого 
SysEx-формата для LED-индикации — вот строка: 
`F0 00 20 6B 7F 42`. Я подключаю через USB и настраиваю 
в OBS через плагин obs-midi.
```

## Алгоритм

```
Текст
  │
  ├──→ Критик 1 (templates) ──┐
  ├──→ Критик 2 (rhythm) ─────┤
  ├──→ Критик 3 (specificity)─┤
  └──→ Критик 4 (generality) ─┘
                               │
                               ▼
                    ┌──────────────────┐
                    │ Агрегация        │
                    │ (объединение     │
                    │  правок)         │
                    └──────────────────┘
                               │
                               ▼
                    ┌──────────────────┐
                    │ Реврайтер        │
                    │ (применение      │
                    │  всех правок)    │
                    └──────────────────┘
                               │
                               ▼
                    ┌──────────────────┐
                    │ Проверка         │
                    │ (score < 3 →     │
                    │  повторить)      │
                    └──────────────────┘
```

## Использование

```bash
# Все критики
claude skill deaify-text "Текст для обработки"

# Конкретные критики
claude skill deaify-text "Текст" --critics templates,specificity

# Несколько итераций
claude skill deaify-text "Текст" --iterations 3

# Из файла
claude skill deaify-text --file ./draft.md
```

## Программный интерфейс

```javascript
const deaify = await claude.skill('deaify-text', {
  text: myText,
  critics: ['templates', 'rhythm', 'specificity', 'generality'],
  iterations: 2
});

console.log(deaify.text);      // Обработанный текст
console.log(deaify.score);     // Оценка качества (1-5)
console.log(deaify.changes);   // Список изменений
```

## Оценка качества

После каждой итерации вычисляется score:

```
Score = 5 - (количество найденных проблем / общее количество предложений)

5 = Отлично (нет проблем)
4 = Хорошо (1-2 проблемы)
3 = Удовлетворительно (3-4 проблемы)
2 = Плохо (5+ проблем)
1 = Критично (требуется полный реврайт)
```

Если score < 3 → повторная итерация с фокусом на проблемных местах.

## Интеграция с blog-post

Skill blog-post автоматически вызывает deaify:

```javascript
// Внутри blog-post skill
const draft = generateDraft(topic, context);

const deaified = await claude.skill('deaify-text', {
  text: draft,
  iterations: 2
});

if (deaified.score < 4) {
  console.warn('Текст требует ручной проверки');
}

return deaified.text;
```

## Настройка

`~/.claude/skills/deaify-text/config.json`:

```json
{
  "critics": {
    "templates": {
      "enabled": true,
      "patterns": [
        "Важно отметить",
        "Стоит отметить",
        "Необходимо понимать",
        "Следует учитывать"
      ]
    },
    "rhythm": {
      "enabled": true,
      "min_sentence_length": 5,
      "max_sentence_length": 30
    },
    "specificity": {
      "enabled": true,
      "require_numbers": true,
      "require_versions": true
    },
    "generality": {
      "enabled": true,
      "require_opinion": true
    }
  },
  "default_iterations": 2,
  "min_score": 3.5
}
```

## Лучшие практики

1. **Всегда используй** перед публикацией
2. **2 итерации** оптимально для большинства текстов
3. **Проверяй score** — если < 3.5, добавь контекста
4. **Не злоупотребляй** — текст должен остаться читаемым
5. **Сохраняй оригинал** — для сравнения

## Проблемы

### Текст стал слишком сухим
→ Уменьши iterations до 1
→ Отключи критика rhythm

### Не хватает конкретики
→ Добавь больше контекста перед deaify
→ Включи критика specificity

### Слишком много правок
→ Разбей текст на части
→ Обрабатывай абзацы отдельно
