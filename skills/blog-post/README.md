# Blog Post Skill

Генерирует статью для блога из темы с использованием research и деаификации.

## Входные данные

- `topic`: Тема статьи (обязательно)
- `context`: Контекст из логов сессии (опционально)
- `style`: Стиль написания (technical|tutorial|story) (по умолчанию: tutorial)

## Выходные данные

- HTML файл статьи с мета-тегами
- Markdown версия для редактирования
- JSON с метаданными

## Пример использования

```bash
claude skill blog-post "Настройка MIDI-контроллера для OBS"
```

## Процесс

### 1. Research (Exa API)

Ищем актуальную информацию по теме:
- Как другие решают эту задачу
- Лучшие практики
- Похожие статьи для контекста

### 2. Генерация черновика

На основе:
- Темы статьи
- Контекста из логов
- Research из Exa

Создаём структуру:
- Заголовок (H1)
- Введение (проблема)
- Основная часть (решение)
- Практический пример
- Выводы

### 3. Deaify (критика)

Запускаем 4 параллельных критика:

**Критик 1: Шаблонные фразы**
```
Найди и замени:
- "Важно отметить" → убрать
- "Стоит отметить" → убрать  
- "Необходимо понимать" → конкретизировать
- "Следует учитывать" → конкретизировать
```

**Критик 2: Ритм**
```
Проверь:
- Одинаковая длина предложений
- Однообразное начало абзацев
- Отсутствие коротких фраз
```

**Критик 3: Конкретика**
```
Добавь:
- Конкретные примеры кода
- Числа и метрики
- Ссылки на источники
- Скриншоты/изображения
```

**Критик 4: Общность**
```
Убери:
- Размытые формулировки
- Очевидные истины
- Отсутствие личного мнения
```

### 4. Сборка HTML

Создаём финальный HTML:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="...">
  <meta name="keywords" content="...">
  <meta name="author" content="...">
  <meta property="og:title" content="...">
  <meta property="og:description" content="...">
  <title>Заголовок статьи</title>
</head>
<body>
  <article>
    <!-- Деаифицированный контент -->
  </article>
</body>
</html>
```

## Интеграция с deaify-text

Skill blog-post автоматически вызывает deaify-text для каждой статьи:

```javascript
// Внутри blog-post
const deaify = await claude.skill('deaify-text', {
  text: draft,
  critics: ['templates', 'rhythm', 'specificity', 'generality']
});
```

## Команды

```bash
# Создать статью
claude skill blog-post "Тема"

# С указанием стиля  
claude skill blog-post "Тема" --style technical

# С контекстом из файла
claude skill blog-post "Тема" --context ./session.log

# Предпросмотр без сохранения
claude skill blog-post "Тема" --dry-run
```

## Настройки

В `~/.claude/skills/blog-post/config.json`:

```json
{
  "exa": {
    "api_key": "${EXA_API_KEY}",
    "results_count": 5
  },
  "output": {
    "dir": "./blog-output",
    "format": ["html", "md"]
  },
  "deaify": {
    "enabled": true,
    "iterations": 2
  }
}
```

## Лучшие практики

1. **Чёткая тема** - одна проблема = одна статья
2. **Контекст** - добавляй логи сессии для точности
3. **Research** - не пропускай шаг поиска
4. **Deaify** - всегда запускай критиков
5. **Ручная проверка** - читай перед публикацией

## Проблемы и решения

### Текст слишком "гладкий"
- Увеличь iterations в deaify
- Добавь больше контекста из логов

### Нет глубины
- Проверь, что Exa нашёл источники
- Укажи конкретные версии софта

### Не похоже на мой стиль
- Добавь примеры своих прошлых статей в контекст
- Настрой критиков в deaify
