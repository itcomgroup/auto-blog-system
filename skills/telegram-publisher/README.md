# Telegram Publisher Skill

Публикует статьи блога в Telegram канал с форматированием и превью.

## Входные данные

- `article_path`: Путь к файлу статьи
- `channel_id`: ID канала Telegram (можно в конфиге)
- `publish_now`: Опубликовать сразу или отложить

## Выходные данные

- Сообщение опубликовано
- Ссылка на пост
- Статистика предпросмотра

## Функционал

### 1. Форматирование

**Превью статьи:**
```
📝 Название статьи

Краткое описание (первые 200 символов)...

#тег1 #тег2 #тег3

🔗 Читать полностью: ссылка_на_сайт
```

### 2. Медиа

- Автоматическая генерация превью (Open Graph)
- Прикрепление изображений из статьи
- Форматирование кода

### 3. Отложенная публикация

```bash
claude skill telegram-publisher ./article.html --schedule "2026-02-06 10:00"
```

## Использование

```bash
# Опубликовать сразу
claude skill telegram-publisher ./my-article.html

# Отложенная публикация
claude skill telegram-publisher ./article.html --schedule "tomorrow 9:00"

# Только превью без публикации
claude skill telegram-publisher ./article.html --dry-run

# Массовая публикация
claude skill telegram-publisher ./output/ --batch
```

## Конфигурация

`~/.claude/skills/telegram-publisher/config.json`:

```json
{
  "bot_token": "${TELEGRAM_BOT_TOKEN}",
  "channel_id": "@myblog_channel",
  "default_schedule": "09:00",
  "format": {
    "emoji": "📝",
    "max_description_length": 200,
    "include_tags": true,
    "include_reading_time": true
  }
}
```

## Требования

```env
TELEGRAM_BOT_TOKEN=your_bot_token_from_botfather
TELEGRAM_CHANNEL_ID=@your_channel_name
```

## Настройка бота

1. Написать @BotFather
2. Создать бота: `/newbot`
3. Получить токен
4. Добавить бота в канал администратором
5. Указать токен в конфиге

## Лучшие практики

- Публикуй утром (9:00-11:00) для максимального охвата
- Используй отложенную публикацию
- Добавляй релевантные хэштеги
- Проверяй превью перед публикацией
