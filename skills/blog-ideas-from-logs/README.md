# Blog Ideas from Logs Skill

Извлекает потенциальные темы для статей из логов сессий Claude Code.

## Проблема

В каждой сессии с Claude Code решается конкретная задача:
- Настроен деплой
- Разобран API
- Найден баг в конфиге

Через неделю всё это теряется в истории чатов.

## Решение

Автоматически сканировать логи и извлекать темы, достойные статей.

## Входные данные

- `logs_dir`: Директория с логами (по умолчанию: ~/.claude/logs/)
- `date_range`: Диапазон дат для анализа
- `min_complexity`: Минимальная сложность темы (1-5)

## Выходные данные

JSON массив тем:
```json
[
  {
    "topic": "Настройка MIDI-контроллера для OBS",
    "complexity": 4,
    "context": "Работал с Akai MPK mini...",
    "tags": ["obs", "midi", "hardware"],
    "files": ["obs-midi.md", "sysex-commands.txt"],
    "session_date": "2026-01-15"
  }
]
```

## Критерии хорошей темы

### 1. Решена нестандартная задача
```
✓ "Настроил деплой через GitHub Actions с кастомным Docker образом"
✗ "Установил npm пакет"
```

### 2. Были ошибки и их решение
```
✓ "Ошибка CORS → добавил заголовки в nginx.conf"
✗ "Всё сработало с первого раза"
```

### 3. Использованы конкретные технологии
```
✓ "Claude Code + Exa API + Astro"
✗ "Пофиксил баг"
```

### 4. Может быть полезно другим
```
✓ "Интеграция Stripe с вебхуками"
✗ "Переименовал переменную"
```

## Использование

```bash
# Сканировать все логи
claude skill blog-ideas-from-logs

# За последнюю неделю
claude skill blog-ideas-from-logs --days 7

# Только сложные темы
claude skill blog-ideas-from-logs --min-complexity 4

# Сохранить в файл
claude skill blog-ideas-from-logs --output ./ideas.json
```

## Интеграция с blog-post

```bash
# Получить идеи и сразу создать статью
claude skill blog-ideas-from-logs --limit 1 | \
claude skill blog-post --from-stdin
```

## Структура анализа

### Шаг 1: Парсинг логов

Логи Claude Code хранятся в формате:
```
~/.claude/logs/
├── 2026-01-15/
│   ├── 14-30-22-session.log
│   └── 16-45-11-session.log
└── 2026-01-16/
    └── 10-20-33-session.log
```

Извлекаем:
- Временные метки
- Запросы пользователя
- Ответы Claude
- Исполненные команды
- Файлы с изменениями

### Шаг 2: Идентификация задач

Ищем паттерны:
```
"Настроить", "Разобраться", "Исправить", "Создать"
"Почему не работает", "Как сделать", "Ошибка"
"Нужно", "Требуется", "Хочу"
```

### Шаг 3: Оценка сложности

```
1: Простая задача (< 5 минут)
2: Стандартная задача (5-15 минут)
3: Средняя сложность (15-30 минут)
4: Сложная задача (30-60 минут)
5: Комплексное решение (> 1 часа)
```

Факторы сложности:
- Количество шагов
- Наличие ошибок
- Использование нескольких технологий
- Кастомные решения

### Шаг 4: Фильтрация

Убираем:
- Повторяющиеся темы
- Слишком простые (< 2)
- Контекстно-зависимые (специфичные только для этого проекта)

### Шаг 5: Ранжирование

Сортируем по:
```
score = complexity × uniqueness × utility

uniqueness: Насколько редкая тема
utility:    Насколько полезна другим
```

## Конфигурация

`~/.claude/skills/blog-ideas-from-logs/config.json`:

```json
{
  "logs_dir": "~/.claude/logs",
  "min_complexity": 3,
  "max_ideas": 10,
  "exclude_patterns": [
    "test",
    "debug",
    "wip"
  ],
  "output": {
    "format": "json",
    "dir": "./blog-ideas"
  }
}
```

## Лучшие практики

1. **Запускай регулярно** — раз в неделю
2. **Проверяй руками** — AI может пропустить хорошую тему
3. **Сохраняй контекст** — чем больше деталей, тем лучше статья
4. **Группируй похожие** — несколько мелких → одна большая статья

## Интеграция в CI/CD

```yaml
# .github/workflows/extract-ideas.yml
name: Extract Blog Ideas
on:
  schedule:
    - cron: '0 9 * * 1'  # Каждый понедельник

jobs:
  extract:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Extract ideas
        run: |
          claude skill blog-ideas-from-logs --output ideas.json
          cat ideas.json
```
